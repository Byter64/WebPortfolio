# Portfolio

Ein minimales, statisches Portfolio für GitHub Pages – ohne Framework und ohne Build-Schritt.

## Auf GitHub Pages veröffentlichen

1. Dieses Verzeichnis in ein GitHub-Repository übertragen.
2. Im Repository **Settings → Pages** öffnen.
3. Unter **Build and deployment** die Quelle **Deploy from a branch** wählen.
4. Den Branch `main` und den Ordner `/(root)` auswählen und speichern.

Danach veröffentlicht GitHub die Seite. Änderungen an `index.html` oder `styles.css` werden mit dem nächsten Push übernommen.

## Lokal ansehen

Die Datei `index.html` kann direkt im Browser geöffnet werden.
